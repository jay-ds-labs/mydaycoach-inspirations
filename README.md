# MyDayCoach Inspiration Library

Public, curated content feed for the MyDayCoach Android app. This repository contains no application code, credentials or user information.

`library.json` is a versioned JSON feed. Every entry requires an HTTPS source and a practical takeaway. Original editorial reflections are labelled as such, not presented as historical quotations.

New items are added after editorial review. Content is not AI-generated on demand by the app.
